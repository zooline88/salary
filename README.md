# 실수령액 계산기

연봉·월급의 실수령액을 계산해 주는 정적 웹사이트입니다.
서버가 필요 없고, 계산은 전부 방문자의 브라우저 안에서 이뤄집니다.

---

## 어떻게 확인하나요?

`index.html` 파일을 **더블클릭**하면 브라우저에서 바로 열립니다. 설치할 것 없습니다.

## ★ 매년 해야 하는 갱신 작업

요율은 시점마다 바뀝니다. **코드는 건드릴 필요 없고 아래 두 파일만** 손보면 됩니다.

### 1) 매년 7월 — 국민연금 상·하한액

`assets/js/rates.js` 배열 **맨 앞에** 새 항목을 추가합니다.

```js
{
  id: '2027-2H',
  effectiveFrom: '2027-07-01',
  effectiveTo:   '2028-06-30',
  label: '2027년 7월 ~ 2028년 6월 기준',
  nationalPension: { employeeRate: 0.0475, totalRate: 0.095,
                     baseMin: 000000, baseMax: 0000000 },   // ← 새 상·하한액
  ...
}
```

확인처: 보건복지부 「국민연금 기준소득월액 하한액과 상한액」 고시

### 2) 매년 1월 — 건강보험·장기요양보험 요율

같은 파일의 `healthInsurance.employeeRate`(총요율의 절반)와
`longTermCare.rateOfHealth`(건강보험료 대비 비율)를 고칩니다.

확인처: 국민건강보험공단 보도자료, 보건복지부 고시

### 3) 세법 개정 시 — 근로소득 간이세액표

1. 국가법령정보센터에서 **소득세법 시행령 [별표 2]** PDF를 내려받습니다.
2. 아래를 실행합니다.

```bash
pip install pypdf
python tools/build_withholding_table.py "내려받은표.pdf" 2027
```

3. `assets/data/withholding-2027.js`가 생깁니다.
   각 HTML의 `<script src=".../withholding-2026.js">`를 새 파일명으로 바꿉니다.
4. **자녀세액공제 금액**과 **월급여 1,000만원 초과 산식**은 자동 추출되지 않습니다.
   PDF의 비고 3번과 마지막 페이지를 눈으로 확인해 `tools/build_withholding_table.py`
   안의 `childCredit` / `overMax` 값을 고친 뒤 다시 실행하세요.

### ★ 4) 파일을 고쳤으면 반드시 "버전 숫자"도 같이 올릴 것

각 HTML 안의 CSS·JS 주소 뒤에 `?v=20260731` 같은 숫자가 붙어 있습니다.

```html
<link rel="stylesheet" href="assets/css/style.css?v=20260731">
<script src="assets/js/rates.js?v=20260731"></script>
```

이 숫자를 **오늘 날짜로 바꾸지 않으면**, 이미 사이트를 방문했던 사람의 브라우저는
예전 파일을 계속 쓰기 때문에 **요율을 고쳐도 화면이 안 바뀝니다.**
`rates.js`나 `calc.js`, `style.css`를 고쳤다면 모든 HTML의 `?v=` 뒤 숫자를
새 날짜(예: `?v=20270701`)로 일괄 바꾸세요.

## 배포 방법 (GitHub Pages)

1. GitHub에서 새 저장소를 만듭니다. **저장소 이름은 `salary`** 로 하세요.
   (사이트 안의 주소들이 `zooline88.github.io/salary/` 기준으로 적혀 있습니다.
   다른 이름을 쓰려면 아래 "주소 바꾸기"를 참고하세요.)
2. 이 폴더의 파일을 전부 올립니다.
3. 저장소 Settings → Pages → Branch를 `main` / `/ (root)`로 지정합니다.
4. 몇 분 뒤 `https://zooline88.github.io/salary/` 로 열립니다.

### 주소 바꾸기
저장소 이름이나 도메인이 다르면 아래 세 군데의 `https://zooline88.github.io/salary/`를
새 주소로 일괄 바꾸면 됩니다.
- 각 HTML의 `<link rel="canonical">` 와 `og:url`
- `sitemap.xml`
- `robots.txt`
- `404.html` 안의 `/salary/` 경로들

## 애드센스

- `ads.txt`에 퍼블리셔 ID(`pub-5521043113375613`)가 들어 있습니다.
- 각 페이지 `<head>`에 애드센스 로더 스크립트가 이미 들어 있습니다.
- 광고를 넣을 자리는 HTML 안에 이렇게 표시해 두었습니다.

```html
<div class="ad-slot">
  <!-- 애드센스 광고 단위 코드를 이 자리에 붙여넣으세요 -->
</div>
```

애드센스에서 **광고 단위를 만든 뒤 나오는 코드**를 이 주석 자리에 붙여넣으면 됩니다.
계산기 입력폼과 결과 사이에는 일부러 광고 자리를 넣지 않았습니다(이탈률 방지).

배포 후 애드센스 관리화면에서 **사이트 추가 → 새 주소 등록**을 해야 광고가 나옵니다.
