사이트 소개

복잡한 급여 계산을 누구나 1초 만에 확인할 수 있게 만드는 것이 목표입니다.

무엇을 하는 사이트인가요?

연봉이나 월급을 넣으면 4대보험료와 세금을 뺀 실제 수령 금액을 계산해 주는 도구 모음입니다. 실수령액 계산기, 연봉 실수령액 계산기, 4대보험 계산기, 퇴직금 계산기, 연봉 실수령액표를 제공합니다. 회원가입이 없고 전부 무료입니다.

계산 근거

  • 소득세 — 소득세법 시행령 [별표 2] 근로소득 간이세액표(2026. 2. 27. 개정)의 원본 데이터 전체를 그대로 넣어 조회합니다. 근사식이 아닙니다. 월급여 1,000만원 초과 구간은 같은 별표에 고시된 산식을 적용합니다.
  • 4대보험료 — 2026년 국민연금(9.5%)·건강보험(7.19%)·장기요양보험(건강보험료의 13.14%)· 고용보험(실업급여 0.9%) 요율을 적용합니다. 국민연금 기준소득월액 상·하한액은 보건복지부 고시(2026년 7월~2027년 6월: 상한 659만원 / 하한 41만원)를 따릅니다.
  • 퇴직금 — 근로기준법 제2조의 평균임금 정의와 근로자퇴직급여보장법의 법정 퇴직금 산식을 적용합니다.

요율은 어떻게 갱신하나요?

요율과 상·하한액은 코드가 아니라 별도의 설정 파일로 분리해 두었습니다. 개정이 있을 때 해당 파일만 갱신하면 모든 계산기에 동시에 반영됩니다. 갱신 주기는 다음과 같습니다.
